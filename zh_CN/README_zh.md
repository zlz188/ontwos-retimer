# On-Twos 一拍二重定时（中文版）

把【约束/物理】驱动的骨骼动画转换为步进式**一拍N**（每 N 帧定格一次）的关键帧动画，分两步完成：

1. **烘焙姿态 → 骨骼关键帧**：逐帧采样约束/物理求值后的最终姿态并写入骨骼关键帧（可选锁定驱动设置）。
2. **应用一拍N**：对关键帧抽稀（保留满足 `(帧-相位)%N==0` 的帧）并设为恒定插值，实现经典"定格"效果。

适用于**任何骨骼被约束/物理驱动**的骨架（IK、阻尼追踪、刚体模拟、布料/头发链条等），**无需搭配其他插件**。

## 功能特性

- **烘焙姿态 → 骨骼关键帧**：一键还原驱动设置、逐帧采样最终姿态、写入关键帧；可选锁定驱动（静默约束 + 关闭物理世界）
- **目标骨骼**：姿态模式选中的骨骼（默认）/ MMD 刚体跟踪骨（可选兼容模式，默认关闭）
- **包含子链**：勾选后选中父级骨骼自动覆盖整条子链（如选中骨盆即可覆盖整条腿链）
- **高亮目标骨骼**：点击后在姿态模式高亮显示将被烘焙的骨骼，不做任何修改
- **两遍烘焙选项**：既保留阻尼的柔顺观感，又是确定、可回跳的结果
- **应用一拍N**：抽稀 + 恒定插值（一拍二=2，一拍三=3）
- **步进插值模式**：同曲线编辑器手动操作，非破坏，只作用于目标骨骼通道
- **密集曲线检测**：只处理像烘焙（密集）动画的曲线，绝不触碰手K动画
- **恢复**：从随文件保存的备份动作精确恢复；无备份时通用兜底（移除步进修改器 / 平滑恒定插值）
- 所有操作均可 Ctrl+Z 撤销，非破坏优先
- 兼容 Blender 4.x / 5.0

## 安装

与英文版**二选一**安装（两者 ID 相同，后装的会替换先装的，请勿同时安装）：

1. Blender → 编辑 → 偏好设置 → 扩展（Get Extensions）→ 右上角 **≡** → **从磁盘安装**（Install from Disk）；
2. 选择下载的 `.zip`，启用 **On-Twos 一拍二重定时（中文版）**。

> 传统方式：Blender → 编辑 → 偏好设置 → 插件 → 安装，选择 `.zip` 即可。

## 使用

1. 选中骨骼被约束/物理驱动的骨架；
2. 3D 视图右侧 N 面板「**一拍二**」标签页：
   - a. 设好帧范围与目标骨骼 → 点击【烘焙姿态→骨骼关键帧】；
   - b. 可先点【高亮目标骨骼】确认影响范围 → 点【应用一拍N】。
3. 效果不满意：Ctrl+Z；或【恢复驱动（解锁）】后重新烘焙。
